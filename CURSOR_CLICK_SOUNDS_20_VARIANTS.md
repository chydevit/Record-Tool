# Cursor Click Sounds - 20 Variants! 🎵

## Overview

The cursor click sound system now includes **20 unique sound variants** that users can select from the UI. Each sound has distinct characteristics and is generated procedurally using the Web Audio API.

## Technical Specifications

### Sound Generation Methods

1. **Sine Wave** (Pure tones)
   - Default, Soft, Pop, Bubble, Wooden, Chirp, Bell, Drum, Thud

2. **Square Wave** (Sharp, digital)
   - Mechanical, Coin, Tick

3. **Sawtooth Wave** (Bright, buzzy)
   - Laser, Whomp

4. **Triangle Wave** (Warm, mellow)
   - Wooden

5. **Noise-Based** (Textured)
   - Snap, Swoosh, Zap

6. **Multi-Oscillator** (Complex, rich)
   - Metallic, Glass, Bell, Coin

### Frequency Ranges

```
Ultra High (3000-5000Hz): Glass, Zap, Chirp
High (1500-3000Hz):       Mechanical, Beep, Tick, Metallic
Mid (800-1500Hz):         Default, Soft, Bell, Coin, Laser
Low (300-800Hz):          Wooden, Bubble, Pop
Very Low (50-300Hz):      Thud, Drum, Whomp
```

### Duration Classification

```
Very Short (50-80ms):  Tick, Snap, Beep, Soft, Zap
Short (90-120ms):      Mechanical, Default, Swoosh, Drum, Chirp
Medium (150-200ms):    Pop, Thud, Metallic, Bubble, Coin, Laser
Long (250-300ms):      Glass, Bell
```

## Accessibility Considerations

### Volume Perception
- **Quietest**: Soft, Tick
- **Moderate**: Default, Wooden, Chirp, Bell
- **Loud**: Snap, Drum, Thud, Whomp, Metallic, Glass

### Frequency Sensitivity
- **High Frequency** (may be harsh): Glass, Zap, Chirp, Metallic
- **Mid Frequency** (comfortable): Default, Soft, Beep, Bell
- **Low Frequency** (may rumble): Thud, Drum, Whomp

### Recommendations
- For hearing sensitivity: Use Soft, Wooden, or Bell
- For clarity: Use Tick, Snap, or Mechanical
- For comfort: Use Default, Soft, or Bubble
