# Sound Variants - Visual Comparison

## Frequency & Duration Comparison

```
Sound Variant    Frequency Range        Duration    Waveform
═══════════════════════════════════════════════════════════════
Default          1200Hz → 800Hz         100ms       Sine
Soft             1000Hz → 700Hz          80ms       Sine (quiet)
Mechanical       1500Hz → 1000Hz         60ms       Square + Filter
Pop              2000Hz → 400Hz         150ms       Sine (wide sweep)
Bubble           600Hz → 300Hz → 450Hz  200ms       Sine (wobble)
Wooden           400Hz → 250Hz           90ms       Triangle + Filter
Metallic         2400Hz + 3200Hz        180ms       Dual Sine (ring)
Glass            3800Hz + 5200Hz        250ms       Dual Sine (high)
Swoosh           2000Hz → 800Hz         120ms       Filtered Noise
Beep             1800Hz (constant)       80ms       Pure Sine
```
